# LearnWithMe 📚

### Learn. Create. Share. Grow.

**LearnWithMe** is my personal learning blog where I document and share my journey of exploring technology, programming, and computer science.

This platform is a place to share what I learn, showcase projects, explain technical concepts, and grow together through knowledge sharing.

## 🌸 About the Project

I'm Guna Sekhar, an Integrated M.Tech CSE student. I created LearnWithMe to turn my everyday learning experiences into something valuable that others can explore and learn from.

Instead of keeping my learning journey to myself, I wanted to build a platform where I can document concepts, share discoveries, and showcase my work.

## ✨ Features

- 📝 Blog articles and technical explanations
- 💻 Programming and computer science topics
- 📚 Dedicated learning categories
- 🚀 Personal projects showcase
- 👤 About the author section
- 📩 Contact and newsletter features
- 🔐 Secure admin authentication
- ✍️ Admin dashboard for managing blog content

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Styling:** Tailwind CSS
- **Backend & Database:** Firebase
- **Database:** Cloud Firestore
- **Authentication:** Firebase Authentication
- **File Storage:** Firebase Storage
